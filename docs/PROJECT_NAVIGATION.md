# 🧭 Навигация по проекту

## 🚀 Быстрый старт
```bash
# Активация и запуск
source activate_venv.sh
python3 kemono_gui_v6.py
```

## 📍 Где что находится

### 🔍 **Ищете тесты?** 
→ `tests/` (все test_*.py файлы)

### 📖 **Нужна документация?**  
→ `docs/` (README, GUIDE, инструкции)

### 🐛 **Отладка проблем?**  
→ `debug/` (диагностика, анализ)

### 📄 **HTML примеры?**  
→ `html_samples/` (сохраненные страницы)

### 🕰️ **Старые версии?**  
→ `legacy/` (предыдущие версии GUI)

### ⚡ **Готовые скрипты?**  
→ `scripts/` (быстрый старт, примеры)

## 🎯 Основные файлы (в корне)

- **`kemono_gui_v6.py`** - главное приложение
- **`kemono_parser.py`** - основной парсер  
- **`interactive_downloader.py`** - загрузчик контента
- **`activate_venv.sh`** - активация окружения
- **`requirements.txt`** - зависимости

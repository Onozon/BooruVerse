# 🎨 Kemono.cr Parser - Простой гайд по использованию

## 📖 О чем этот гайд?

Этот гайд поможет вам научиться использовать **Kemono.cr Parser** - инструмент для автоматического скачивания медиафайлов (изображений, видео, архивов) из постов авторов на платформе kemono.cr.

## 🚀 Быстрый старт (3 шага)

### Шаг 1: Установка
```bash
# Скачайте и установите зависимости
pip install -r requirements.txt
```

### Шаг 2: Запуск
```bash
# Запустите интерактивный загрузчик
python interactive_downloader.py
```

### Шаг 3: Использование
```
🎨 Kemono.cr Интерактивный Загрузчик Медиафайлов
Введите URL автора: https://kemono.cr/fanbox/user/3065392
🚀 Начать скачивание? y
✅ Готово! Файлы скачаны в папку downloads/
```

## 📋 Подробная инструкция

### Что умеет парсер?

✅ **Автоматически находит** все посты автора
✅ **Скачивает все медиафайлы** (фото, видео, архивы)
✅ **Организует файлы** в удобную структуру папок
✅ **Показывает прогресс** скачивания
✅ **Работает с любыми авторами** (Patreon, Fanbox, Gumroad и др.)

### Формат URL автора

Парсер работает с URL вида:
- `https://kemono.cr/patreon/user/123456`
- `https://kemono.cr/fanbox/user/3065392`
- `https://kemono.cr/gumroad/user/789012`

### Как найти URL автора?

1. Зайдите на [kemono.cr](https://kemono.cr)
2. Найдите нужного автора через поиск
3. Скопируйте URL из адресной строки браузера

## 🎯 Режимы использования

### 1. Интерактивный режим (Рекомендуется)

```bash
python interactive_downloader.py
```

**Что происходит:**
- Вводите URL автора
- Парсер находит все посты
- **Выбираете количество** постов для скачивания
- Автоматическое скачивание всех медиафайлов

**Пример диалога:**
```

🚀 Скачать медиафайлы из 3 постов? (y/n): y

⬇️  Начинаю скачивание...

   🔍 Загружаю медиафайлы с страницы поста...
```

### 2. Пакетный режим

```bash
# Скачать все посты автора
echo "all" | python interactive_downloader.py
```

### 3. Программное использование

```python
from kemono_parser import KemonoParser

parser = KemonoParser()
artist = parser.create_artist_from_url("https://kemono.cr/fanbox/user/3065392")
posts = parser.get_all_artist_posts(artist)

for post in posts[:5]:  # Первые 5 постов
    parser.download_post_content(post, "downloads", artist)
```

## ⚙️ Настройки и возможности

### Ограничение количества постов

При большом количестве постов парсер предложит выбрать:
- **1-5 постов** для тестирования
- **all** для скачивания всех постов

### Типы скачиваемых файлов

Парсер скачивает:
- 🖼️ **Изображения**: JPG, PNG, GIF, WebP
- 🎬 **Видео**: MP4, AVI, MOV
- 📦 **Архивы**: ZIP, RAR
- 📄 **Документы**: PDF

### Скорость скачивания

- Показывает **прогресс-бар** для каждого файла
- **Размеры файлов** от килобайт до гигабайт
- **Автоматическое продолжение** при обрыве связи

## 🔧 Устранение проблем

### Проблема: "Не найдено ни одного поста"

**Решение:**
- Проверьте правильность URL
- Убедитесь, что автор существует на kemono.cr
- Попробуйте другой URL автора

### Проблема: Файлы не скачиваются

**Решение:**
- Проверьте интернет-соединение
- Попробуйте скачать меньше постов
- Проверьте свободное место на диске

### Проблема: Парсер зависает

**Решение:**
- Закройте программу (Ctrl+C)
- Попробуйте скачать меньше постов
- Проверьте использование памяти

## 📊 Статистика и отчеты

После скачивания парсер показывает:
- 📊 Количество скачанных файлов
- ⏱️ Время выполнения
- 📁 Путь к папке с файлами
- ⚠️ Количество ошибок (если есть)

## 🎯 Советы по использованию

### Для тестирования:
- Скачивайте **1-2 поста** сначала
- Проверьте структуру файлов
- Убедитесь, что файлы открываются

### Для больших объемов:
- Скачивайте в **отдельное время**
- Убедитесь в **стабильном интернете**
- Проверьте **свободное место** (минимум 10GB)

### Для регулярного использования:
- Создайте **отдельную папку** для каждого автора
- **Резервное копирование** важных файлов
- Следите за **обновлениями** парсера

## ❓ Часто задаваемые вопросы

**Q: Сколько файлов можно скачать за раз?**
A: Нет ограничений, но рекомендуется начинать с малого количества.

**Q: Можно ли скачивать только изображения?**
A: Сейчас скачиваются все медиафайлы. Можно модифицировать код для фильтрации.

**Q: Работает ли с Patreon/Fanbox/Gumroad?**
A: Да! Парсер работает со всеми поддерживаемыми платформами kemono.cr.

**Q: Что делать если парсер не работает?**
A: Проверьте интернет, попробуйте другой URL, или обратитесь за помощью.
